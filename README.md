# Windhorse Rumble

A Road-Rash-style horse racing brawler set in Tibet in the Wood Horse Year (1954), told as an old rider's tall tale.
Speed wins races, and so does knocking everyone else off their horses.

**To play:** double-click `Play.command` on macOS, or `Play.bat` on Windows (untested). It needs Godot 4.7. The first
launch may ask you to allow it.

## Controls

| Action | Keyboard | Gamepad (untested) |
|---|---|---|
| Steer, urge, rein in | WASD or arrows | Left stick, RT, LT |
| Whip (sprint, burns stamina) | Left Shift | RB |
| Leap | Space | A |
| Strike left / right | J / L, or Q / E, or left / right mouse | X / B |
| Kick | K or F | Y |
| Ranged weapon (hold to draw, release to fire) | U or R | Right stick click or D-pad up |
| Shield (hold) | I or C | LB |
| Second Wind (when all five flags are lit) | Enter or Ctrl | D-pad down |
| Pause | Esc | Start |

## The rules in brief

- Finish in the top 3 on all five courses to raise the Season. There are three Seasons.
- **Health** at zero crashes you, followed by a 7-second rest. Tap to shorten it.
- **Shake** builds with each hit's impact. Above 70 each new hit might unseat you, and at 100 you always fall, even at
  full health. Steering against the wobble calms you faster.
- **Ranged weapons** do far less damage and impact, and can never unseat a rider through impact alone.
- **Lungta** (the five flags) is your fortune. Pass mani walls and chortens with them on your right, cross high passes,
  parry and perform stunts to raise it.
- **Quiet Ground:** no fighting. It costs you fortune and silver.

## What's where

- `docs/`: design, style, world and cast, assets, architecture, research and its limits
- `docs/RESEARCH.md` summarises the research. The long-form notes stay on the original computer and aren't in this repo
- `art/`: scripts that generate every model, texture, font and sound
- `assets/`: generated output, don't edit by hand
- `scripts/`, `scenes/`, `shaders/`, `data/`: the game
- `tests/`: `sim_balance` (headless rule checks), `autoplay` (bot plays with rendering), `lookdev` (art review)
- `tools/record_demo.sh`: records the demo video from real gameplay

## Setting up on another computer

Ask Claude Code on that computer to clone this repo and follow `docs/NEW_COMPUTER_SETUP.md`. `docs/HANDOFF.md` says where
the project stands. Models, textures and sounds are in Git LFS, so a clone without it gets placeholder files.

There are no `.blend` files. Every model is generated by the scripts in `art/blender/`, and the results are in
`assets/models/` as `.glb`, which Blender can open directly.
