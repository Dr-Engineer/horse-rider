# Windhorse Rumble

Road-Rash-style horse combat racing, Tibet, 1954, Godot 4.7 and Blender 5.2. Claude does all the work and is the
user's only interface.

Read before changing anything:
- `docs/GAME_DESIGN.md`: rules, numbers, and the binding cultural rules
- `docs/STYLE_GUIDE.md`: the visual rules
- `docs/WORLD_AND_CAST.md`: story, courses, cast
- `docs/ASSET_BIBLE.md`: every asset and the script that builds it
- `docs/TECH_ARCHITECTURE.md`: code layout and coordinate conventions
- `docs/RESEARCH.md`: findings and their limits
- `docs/HANDOFF.md`: where the project stands, how the user works, what's next
- `docs/VOICE_SCRIPT.md`: every Tibetan phrase and how the voices are made, laid out for review by a Tibetan speaker
- `docs/NEW_COMPUTER_SETUP.md`: installing everything on a new computer

Practical notes:
- **Godot must never interrupt the user.** Anything that needs pixels goes through `tools/run_hidden.ps1` (Windows), which runs it on
  an invisible desktop with audio off. Anything else uses `--headless`. Only open a visible window if the user asks to watch.
- The user muted the game on their PC. Leave their settings file alone. Runs of `res://tests`, `res://tools` and `-s` use scratch save
  and settings files, because Godot started from a session writes to the real user data folder. Keep new tests on those paths.
- Blender can run with `--background` for anything that only exports. The MCP needs Blender 5.2 open in a window, and `tools/bmcp.py`
  calls it if the session's own tools aren't loaded.
- After changing anything in `assets/`, run `tools/godot_import.sh` (set `GODOT` if it isn't in `/Applications`).
- Voices are generated by `art/tools/make_voices.py` from `art/tools/voice_script.py`, with speech models kept outside the repo. See
  `docs/VOICE_SCRIPT.md`. Changing a line of menu text means regenerating it: run `tools/export_lines.gd` first. Claude can't hear the
  results, and the Tibetan lines carry a non-commercial licence.
- `assets/` is generated, so change the scripts in `art/`, not the outputs.
- Only start agents when the user asks. Give them strict file ownership (`docs/INTERFACES.md`) and a lighter model: parallel research agents on the heaviest model used up the usage limit quickly.
- The GitHub repo is public. Run the leak check before every push.
