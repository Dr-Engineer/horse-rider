# Handoff

What the first working session knew, for whichever session continues this project. Written on 2026-10-31 on the original
Mac mini, when the user moved to a different computer as their default.

## How the user works

- Claude does all the work and is the only interface. The user doesn't plan to open Blender or Godot themselves. They give
  direction and playtest feedback in chat.
- They asked for parallel agents and tight deadlines. Four Sonnet agents with strict file ownership (`docs/INTERFACES.md`) built the game
  in about 75 minutes. Seven Opus research agents, by contrast, ran through the session and weekly usage limits. Only spawn agents when asked.
- They care about a consistent style and about the game being fun, and they value plain answers to direct questions.

## State of the game

Playable from start to end: 5 courses, 3 seasons, 18 riders, all weapons, HUD, menus, stable shop, saved progress, story, music and sound.

The user's core rules, all implemented and checked by `tests/sim_balance`:
- Ranged weapons do less damage and impact, and can never unseat a rider on impact alone.
- Too much impact can crash a rider even with health left.
- Zero health crashes the rider and forces a rest.

**Tested only by bots and scripts:**
- Full AI races on every course in every season.
- A menu walkthrough with screenshots.
- About 90-100 fps on an M2.
- A fresh clone from GitHub imports and runs a headless race.

**Never checked by a person, and the most likely source of changes:**
- How the controls feel, and whether the difficulty is right. Top 3 is needed on all 5 courses, and a bot with starting gear averages about 4th in Season 1.
- How the audio sounds. Only levels and loop seams were checked numerically.
- Gamepad input.

## Next work, in the user's likely order

1. Their playtest feedback.
2. The Visitors: Mongol riders, cowboys, British and a fantasy horse lord people, designed in `docs/GAME_DESIGN.md`.
   The user asked for the Rohirrim. Tolkien's names and the film designs are actively licensed, so plan an original people with their own name (general guidance, not legal advice).
3. A standalone app, which needs Godot's export templates (a large download, so ask first).
4. Tibetan review of names, dress, story and the dob-dob rival before any wider release. No Tibetan reader has seen any of this.

**Known small flaws:** no rival chatter during races, some hoof sliding on the ground, a few stray ink lines on terrain, and a mud patch that reads as a dark flat shape.

## Decisions worth keeping

- The game is framed as an old rider's tall tale, because no source describes racers fighting on horseback. The frame also licenses the Visitors.
- The cultural rules in `docs/GAME_DESIGN.md` are binding: no sacred objects as weapons or power-ups, no ordained monks as combatants, no real people, the PLA and 1959 stay offstage. Survey stakes and one parked truck appear with no comment.
- All assets are original and generated by scripts, with no third-party files, so there are no licensing questions.
- Git LFS holds models, textures and audio.

## What isn't in this repo

The repo is public, so these stayed on the Mac mini:
- `research_notes/` holds about 280 KB of long-form notes with citations on arms, dress and names, and history. `docs/RESEARCH.md` is the summary.
- `demo/windhorse_rumble_demo.mp4` is 120 MB, over GitHub's file limit. `tools/record_demo.sh` can record a new one.
- `.mcp.json` has local paths. See `.mcp.example.json`.
- The original conversation and Claude's local memory notes, whose useful content is in this file.
